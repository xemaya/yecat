# 台词红队

检查脚本只能数得出来的东西：字数、连接词、情绪词。剩下的要人（或一个没看过这集的 agent）读。

**审稿人必须是新的**：另开一个对话或子 agent，只给它剧本、v2 和这份清单，不给写稿人的思路。写稿人自己审，容易把自己的意图当成读者看得到的东西。

## 给审稿人的提示词

```
你是《和夜一起住》的审稿人。先读：
- docs/第一季设定与12集_v2.md（设定，以及这一集的梗概）
- 准则/写稿.md（写法规矩）
- 准则/连续性.md（前面几集用过什么）
- epNN/剧本.md（要审的这一集）

按下面四个角色依次审。每个角色只报真的有问题的句子或画面，没问题就写“无”。
每条按这个格式：页 / 原句或画面 / 问题 / 改法（直接给改好的句子）。
不要重写整集，不要加新情节。最后给一句总评：这集最可能被截图的是哪一页，最弱的是哪一页。
```

## 四个角色

### 1. 台词医生：日志感、潜台词

- 旁白是不是在报流水账（“我……然后我……”）？
- 有没有哪句旁白，删掉以后这页照样看得懂？有就删。
- 画面里已经有的东西，字里又说了一遍吗？
- 有没有哪句在解释情绪或动机？能换成一个动作吗？
- 对白是不是一问一答、句句完整？真人会打断、会答非所问、会只说半句。
- 第 9 页是不是把主题说出来了？

### 2. 人设守门：夜和晴

- 夜：每句 8 个字以内吗？有没有指令句（“睡。”“穿厚点。”）、讲道理的关心（“你更累。”）、网文男主腔（“这句，我自己说。”）、元梗（“这是我的词。”）？
- 夜：这句换成一个人类男友来说也成立吗？成立就说明不够“夜”。
- 晴：她这集有没有用自己的本事（动手调灯、接线、测光表、粉笔；上屏的字里不能有 2700K、色温这类术语）？她是在被照顾，还是也在照顾它？
- 晴：她问了它的工作吗？约法第三条，她一次都不能问。
- 晴：这集的反撩手法和 `准则/连续性.md` 里前面几集撞了吗？

### 3. 目标读者：26 岁，一个人在大城市租房

- 哪一页会让我截图？截图点是不是正好是尾尖闪的那一页？
- 哪一页我会划走？
- 这集的甜是“被看见”“被等”“被偏爱”里的哪一种？和上一集一样吗？
- 有没有哪个桥段我在别的甜宠里见过（发烧、卡门框、读心、蓄谋已久、英雄救美）？

### 4. 连续性

- 对照 `准则/连续性.md`：借口链、约法三章、鞋盒里的灯泡、交接灯、尾尖闪、体型、第 9 页收法，有没有冲突？
- 参考图的状态和这一格一样吗（有没有雨、有没有猫、灯亮不亮）？连着两格，人和猫的左右位置一致吗？
- 对照 v2 的规则：夜里的东西只在黑里、而且她得看够五分钟才看得见；工钱是星；体型只跟光走。这集有没有违反？
- 画面里有没有 AI 出图做不到的东西：画面里的字、一个人三只手、要连续好几页保持一致的复杂道具？

## 审完以后

写稿人逐条处理：改，或者在剧本“自审”一节写明为什么不改。审稿人的原话不进仓库，只记结论。
