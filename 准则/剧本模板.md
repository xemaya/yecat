# 剧本模板

每集一个 `epNN/剧本.md`（NN 两位数）。格式是固定的，`tools/check_script.py` 按它解析，视频方也可以直接 `import` 它拿到页面列表（见文末）。

## 格式

````markdown
# 第 02 集｜灯罩里没有灯泡，只有一颗星星

## 本集
- 揭开：v2“本季揭到哪一层”里这一集的那一格
- 推进：信任 → 心动
- 借口：那就是风            （借口链这一集的词；没有就写“无”）
- 尾尖闪：P7                （没有就写“无”）
- 名场面：P6
- 画面字：P8b               （纸条、星光字、飘字在哪；没有就写“无”）
- 通宵：否
- 体型：家猫                （家猫 / 沙发大）
- 第9页收法：晴              （旁白 / 晴 / 夜 / 纸条 / 空镜）
- 她的手法：拆穿它的借口
- 偏离 v2：无               （有就写改了什么、为什么）

## P1 封面
- 拍点：一句话，读者看到这页该知道或感到什么
- 画面：只写拍得到的东西
- 字：
  - 标题：灯罩里没有灯泡，只有一颗星星

## P2
- 拍点：……
- 画面：……画面里没有猫。
- 字：
  - 旁白：楼下那盏灯，只在我加班的晚上亮。

## P5 两格
- 拍点：……
- 画面a：上格……
- 画面b：下格……
- 字：
  - a 晴：……线是断的。
  - b （无字）
- 参考：ep01/art_C/3.png
- 时长：b 5
- 落地备注：H3 首帧、尾帧怎么取，或者用哪种分层动效（建议，视频方定）

## P6 名场面
- 拍点：……
- 画面：……
- 字：
  - （无字）
- 时长：9

（P1–P9 都要有）

## 自审
- 检查脚本：错误 0，警告 N
- 保留的警告：每条写为什么不改
- 台词红队：审稿人提了什么，改了哪些
````

## 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `拍点` | 是 | 一句话。先写完 9 页拍点再写画面。 |
| `画面` / `画面a` `画面b` | 是 | 单格页写 `画面`，两格页写 `画面a`、`画面b`。视频方会把它接上画风、人物描述和 `NO_TEXT` 做出图提示词，所以这里只写场景。 |
| `字` | 是 | 下面每行一句。没有字就写 `（无字）`。 |
| `参考` | 否 | 出图时要照着画的已有插画，路径从仓库根目录写起，多张用顿号隔开。第 1 期画过的东西（路灯、玄关、冰箱）一定要写。检查脚本会查文件在不在。 |
| `时长` | 否 | 建议的镜头秒数，只在无字或要做动作的镜头写。两格页写 `a 4` 或 `b 5`。 |
| `落地备注` | 否 | 给视频方的动效、H3、变体图建议，不进画面。 |

## 一行字怎么写

```
  - [a|b ]说话人：内容[（呼应 第N集）]
```

- 说话人：`标题`、`旁白`、`晴`、`夜`、`纸条（晴）`、`纸条（夜）`、`星光字`、`飘字（晴）`、`飘字（夜）`，配角直接写称呼（`物业`、`小鹿`、`老周`、`妈妈`、`房东`、`爷爷`……）。
- 两格页的字要在前面标 `a ` 或 `b `，表示在哪一格（视频里是哪个镜头）。
- 内容就是最终上屏的字，带标点。夜的省略号写 `……`。
- 故意和前面某集重复的台词，在句尾加 `（呼应 第N集）`，检查脚本就不报重复；这几个字不上屏。

## 视频方怎么用

```python
import sys; sys.path.insert(0, "../tools")
from check_script import parse
ep = parse("剧本.md")
for p in ep.pages:            # p.no、p.scenes（{"": 画面} 或 {"a":…, "b":…}）、p.lines、p.dur
    for ln in p.lines:        # ln.panel（"" / "a" / "b"）、ln.who、ln.text、ln.kind（旁白/晴/夜/画面字/配角/标题）
        ...
```

或者 `python3 tools/check_script.py ep02/剧本.md --json` 直接输出 JSON。
