# 两个 agent 怎么一起推完第一季（草案，等对方回）

目标：照 `docs/第一季设定与12集_v2.md` 推完第 2–12 集，周更。第 1 集已发（`ep01r/`）。
做法和文案规矩以 `配方.md` 为准，有改动两边都改那份。

## 分工

| | 写稿方（另一个 agent） | 视频方（本仓库原作者 agent，跑 4090 / gpt-image / 合成） |
|---|---|---|
| 写 | `epNN/剧本.md`：分镜表（镜头、画面、旁白、夜的台词）、`epNN/视频正文.txt` | 出图、变体图、H3、动效、成片；`epNN/镜头表.md`（每个镜头怎么动） |
| 审 | 视频方的样张和成片：剧情、台词、人设前后一致 | 写稿方的剧本：能不能画、能不能动、字数合不合视频节奏 |

## 每集的流程

1. 写稿方提交 `epNN/剧本.md`，进度表改成「剧本待审」。
2. 视频方审，意见写进 `epNN/审校.md`。要改就改成「剧本要改」，过了就改成「剧本定稿」。
3. 视频方出样张（关键 2–3 张图 + 一个动起来的镜头），改成「样张待审」，写稿方审。
4. 视频方出成片，改成「成片待审」，写稿方审。
5. **用户看成片过审以后**才发小红书。发布只由视频方用 ego-browser 做，发完改成「已发」。

一集在第 3–5 步时，写稿方可以先写下一集，最多领先两集。

## 文件和提交

- 两边都直接推 `main`，只改自己负责的文件。推之前先 `git pull --rebase`。
- 留言写在 `epNN/审校.md` 里，按时间往下追加，每条开头写 `【写稿方 11-05 15:20】` 或 `【视频方 …】`。不改对方的留言。
- 跨集的事、改约定，写在本目录的 `留言.md`，格式同上。
- 成片、mp4、中间图不进仓库，见 `.gitignore`。成片放在视频方本地，审片时视频方在 `审校.md` 里贴抽帧总览图（jpg 进仓库）。
- 提交说明的开头写 `[写稿] ep02 …` 或 `[视频] ep02 …`。
- 有 issue 权限的话，一集也可以开一个 issue，但以仓库里的文件为准（对方之前写 GitHub 报过 403）。

## 节奏

两边都每 10 分钟 `git pull` 一次，看 `协作/进度.md`、`协作/留言.md` 和轮到自己的 `审校.md`。

## 要用户拍板的

- 每集成片发布前要用户过审。
- 动设定的事要用户拍板：改 v2 大纲的剧情走向，加新角色，加音效（比如 v2 里的风哨）。
